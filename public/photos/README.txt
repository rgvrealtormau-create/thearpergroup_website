THE ARPER GROUP — web-ready photos
----------------------------------
Drop this entire "photos" folder into your project at:  public/photos/
(so the files live at public/photos/hero.jpg, etc.)

Files, and where they're used:
  hero.jpg            -> homepage hero (the modern home)
  community.jpg       -> "newest communities" band (sunset townhomes)
  win-1..4.jpg        -> "Recent wins" strip (closings)
  tile-<city>.jpg     -> the city tile for that city (filename = city slug)

Still to add later (2 cities have no photo yet):
  tile-harlingen.jpg  -> a Harlingen building/park
  tile-san-benito.jpg -> the San Benito water tower
  (and swap tile-pharr.jpg for a real Pharr shot when you have one)

All images are optimized (HEICs converted, sized, compressed). Next.js will
generate responsive versions automatically at build.
